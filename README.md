# くりーんぶんしょ

AI が生成した文章や Web からコピーした文章に混ざる **見えない文字**（ゼロ幅スペース、特殊な空白、書字方向の制御文字など）を、Mac で手間なく取り除くメニューバー常駐アプリです。

- 対応：macOS 26 Tahoe 以降、Apple シリコン（M1 以降）
- 画面は日本語のみ。設定はそれぞれの Mac に保存されます
- 文章はどこにも送信されません（すべて Mac の中で処理します）

## 入れ方

1. [Releases](../../releases) から最新の `CleanBunsho-x.y.z.dmg` をダウンロードして開く
2. 「くりーんぶんしょ」を「Applications」フォルダにドラッグする
3. アプリケーションフォルダから「くりーんぶんしょ」を開く
4. 「開けません」と表示されたら、**システム設定 → プライバシーとセキュリティ** を開き、下の方にある「くりーんぶんしょ」の **このまま開く** を押す（最初の1回だけ）

> Apple の有料の開発者登録をしていないため、初回だけこの警告が出ます。

起動するとメニューバーに消しゴムのマークが出ます（Dock には出ません）。

## 使い方

4つの使い方があり、**設定 → 使い方** でそれぞれオン・オフできます（同時に使えます）。

| 使い方 | 操作 | 動き | 既定 |
| --- | --- | --- | --- |
| ショートカット | コピーしたあと **⌃⌥⌘V** | クリップボードをきれいにして、そのまま貼り付ける | オン |
| クリップボード自動監視 | コピーするだけ | コピーされた文字を自動できれいにして上書き | オフ |
| ウィンドウ | メニューバー →「ウィンドウを開く」 | 貼り付けて確認してからコピー | オン |
| 右クリックメニュー | 文字を選んで右クリック →「サービス」→「きれいにする」 | 選んだ箇所をその場で置き換える | オン |

- 文字を消したときは「3個を削除しました」と通知します（設定でオフにできます）
- 何も見つからなかったときはクリップボードを書き換えません（文字の書式を壊さないため）
- 自動監視は、パスワード管理アプリからのコピー（秘密情報の印が付いたもの）には触りません
- メニューバーの「クリップボードをきれいにする」は、きれいにするだけで貼り付けはしません

### ショートカットについて

- 初めてショートカットを押したとき、自動で貼り付けるために **アクセシビリティ** の許可を求めます。
  **システム設定 → プライバシーとセキュリティ → アクセシビリティ** で「くりーんぶんしょ」をオンにしてください。
  許可しない場合は「設定 → 使い方 → 押したあと」を「きれいにするだけ」にすると、⌘V で自分で貼り付けられます
- 他のアプリが先に ⌃⌥⌘V を使っていると登録できません。そのときは設定画面に表示されるので、別のキーを割り当ててください
- 後から他のアプリが同じキーを使い始めた場合は検出できません。効かなくなったら設定でキーを変えてください

### 右クリックメニューが出ないとき

**システム設定 → キーボード → キーボードショートカット → サービス** の「テキスト」にある「きれいにする」をオンにしてください。

## 新しい版に入れ替えたとき

1. 新しい `.dmg` から「くりーんぶんしょ」を Applications に上書きする
2. アプリの署名が版ごとに変わるため、**アクセシビリティの許可を付け直す** 必要があります
   1. **システム設定 → プライバシーとセキュリティ → アクセシビリティ** を開く
   2. 「くりーんぶんしょ」を選んで **−** で消す
   3. くりーんぶんしょを開き直し、ショートカットを押すと出る案内から許可する

## 処理ルール

**設定 → 処理ルール** で1つずつオン・オフできます。

| 種類 | 対象の文字 | 処理 | 既定 |
| --- | --- | --- | --- |
| ゼロ幅文字 | U+200B〜200D、U+2060、U+FEFF、U+00AD など | 削除 | オン |
| 書字方向の制御文字 | U+200E、U+200F、U+202A〜202E、U+2066〜2069 | 削除 | オン |
| タグ文字 | U+E0000〜E007F | 削除 | オン |
| その他の制御文字 | 改行・タブ以外の C0/C1 制御文字 | 削除 | オン |
| 特殊な空白 | U+00A0、U+2000〜200A、U+202F、U+205F | 半角スペースに置換 | オン |
| 全角スペース | U+3000 | 半角スペースに置換 | オフ |
| 行区切り文字 | U+2028、U+2029、U+0085 | 改行に置換 | オン |
| 改行コード | CRLF、CR | LF にそろえる | オン |
| 行末の空白 | 各行の末尾のスペース・タブ | 削除 | オン |
| 先頭と末尾の空白 | 文章全体の前後の半角の空白と改行（全角スペースの字下げは残す） | 削除 | オン |
| 続きすぎた空行 | 3行以上の空行 | 1行にまとめる | オフ |
| カーリークォート | “ ” ‘ ’ | まっすぐな " ' に置換 | オフ |
| ダッシュ | — – | ハイフンに置換 | オフ |

例外：絵文字の間にあるゼロ幅接合子（👨‍👩‍👧 など）と、旗の絵文字（🏴 に続くタグ文字）は残します。

「ゼロ幅文字」には、U+034F・U+180E・U+2061〜2064（見えない演算子）・U+115F/1160/3164/FFA0（ハングルのフィラー）も含みます。
「3個を削除しました」の数は、1文字ずつ処理するルール（削除・置換）の数です。改行コード・行末・先頭末尾・空行の整理は数に入りません。

## 開発

ソースコードは Swift（SwiftUI）。ビルドは GitHub Actions（macOS 26）で行うため、手元に Xcode は不要です。

```
Package.swift
Sources/CleanBunshoCore/   文字処理（UI に依存しない）
Sources/CleanBunsho/       メニューバーアプリ本体
Tests/CleanBunshoCoreTests/
  Fixtures/cases.json      テストケース（入力・期待する結果・削除数・置換数）
Resources/Info.plist       アプリの情報（Dock 非表示、サービスの登録）
scripts/build-app.sh       .app の組み立て・アドホック署名・.dmg 作成
tools/                     参照実装（JavaScript）とテストケースの生成・確認
.github/workflows/build.yml
```

### 処理ルールを変えるとき

1. 先に `tools/make_fixtures.py` の `CASES` にテストケースを足し、`python3 tools/make_fixtures.py` で `cases.json` を作り直す
2. `node tools/check-fixtures.mjs` で参照実装（`tools/reference-cleaner.mjs`）を通す
3. Swift 側（`Sources/CleanBunshoCore/Cleaner.swift`）を同じように直す
4. `main` に push すると GitHub Actions でテストとビルドが走る。できた .dmg は Actions の各実行の **Artifacts** から試せる

`cases.json` は Windows 版でも同じものを通し、処理の結果をそろえます。

### 公開

```sh
git tag v0.1.0
git push origin v0.1.0
```

v で始まるタグを push すると、テスト → ビルド → アドホック署名 → .dmg 作成 → Releases への公開まで自動で進みます。

### 手元で動かす（Xcode か Command Line Tools がある場合）

```sh
swift test
swift run CleanBunsho        # .app にせずに起動（通知・ログイン起動・サービスは .app でのみ動く）
VERSION=0.1.0 scripts/build-app.sh
```
