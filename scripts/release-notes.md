## 入れ方

1. 下の **Assets** から `CleanBunsho-x.y.z.dmg` をダウンロードして開く
2. 「くりーんぶんしょ」を「Applications」フォルダにドラッグする
3. アプリケーションフォルダから「くりーんぶんしょ」を開く
4. 「開けません」と出たら **システム設定 → プライバシーとセキュリティ** を開き、下の方にある「くりーんぶんしょ」の **このまま開く** を押す（最初の1回だけ）

メニューバーに消しゴムのマークが出たら起動しています（Dock には出ません）。

## 前の版から入れ替えたとき

アプリの署名が版ごとに変わるため、ショートカットの自動貼り付けが効かなくなります。次の手順で許可を付け直してください。

1. **システム設定 → プライバシーとセキュリティ → アクセシビリティ** を開く
2. 一覧の「くりーんぶんしょ」を選んで **−** で消す
3. くりーんぶんしょを開き直し、ショートカットを押すと出る案内から許可する

詳しくはリポジトリのトップページ（README）を見てください。
